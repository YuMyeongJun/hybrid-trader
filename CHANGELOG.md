## [0.1.0] - 2026-09-15

### Added
- Initial release of Hybrid Trader
- Support for Korean Investment Service (KIS) API integration
- Support for Upbit cryptocurrency API integration
- Unified HybridTradingEngine for seamless multi-asset trading
- Comprehensive type hints for better IDE support
- Detailed logging system for debugging and monitoring
- Context manager support for safe resource management
- Automatic retry logic for API calls
- Full API documentation
- Comprehensive examples for stock and crypto trading
- Unit tests with pytest
- CI/CD workflow with GitHub Actions

### Features
- Get stock prices via KIS API
- Get cryptocurrency prices via Upbit API
- Unified configuration system (TradingConfig, KISConfig, UpbitConfig)
- Error handling with custom exceptions
- Logging configuration examples
- Demo mode for testing

### Documentation
- Detailed README with quick start guide
- API reference documentation
- Architecture documentation
- Installation guide
- Troubleshooting guide
- Contributing guidelines
- Complete code examples
